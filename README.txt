LUIS SERRANO COACH — WEB GRATUITA

1. Descomprime este ZIP.
2. Abre index.html para ver la web en tu ordenador.
3. Para publicarla gratis, crea una cuenta en github.com y un repositorio público llamado TUUSUARIO.github.io.
4. Sube index.html, styles.css, script.js y la carpeta assets al repositorio (Add file > Upload files).
5. En Settings > Pages, selecciona Deploy from a branch, main, /(root), Save.
6. La web aparecerá en https://TUUSUARIO.github.io (puede tardar unos minutos).
7. Registra esa dirección en Google Search Console.

IMPORTANTE ANTES DE PUBLICAR:
- Revisar textos, enlaces y datos personales.
- Añadir aviso legal y política de privacidad adecuados a tu actividad en España.
- Confirmar el enlace de WhatsApp y los perfiles sociales.
- Añadir dominio propio si decides contratarlo en el futuro.
- El posicionamiento en Google no es inmediato ni garantizado.
